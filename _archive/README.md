# Архив прошлых версий сайта

Здесь хранятся прежние версии сайта, чтобы их можно было посмотреть и вспомнить.
На живой сайт (GitHub Pages) эта папка не попадает: Pages пропускает папки,
имя которых начинается с подчёркивания.

Чтобы посмотреть версию, скачайте репозиторий и откройте `index.html`
нужной папки двойным щелчком.

| Папка | Что внутри |
|---|---|
| `2026-02-original` | Первая версия сайта (январь–февраль 2026): тёмно-коричневый фон, меню-«гамбургер», три страницы |
| `2026-10-design-variants` | Три макета главной страницы (октябрь 2026), из которых выбрали вариант Б — «Строгий тёмный» |

В архивных копиях убран счётчик Google Analytics, чтобы просмотр архива
не засчитывался как посещения сайта.
